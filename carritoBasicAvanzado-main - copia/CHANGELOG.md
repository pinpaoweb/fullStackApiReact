# Registro de Cambios (Changelog)

Todos los cambios notables en este proyecto se documentarán en este archivo.

## [1.1.0] - 2026-07-16
### Añadido
- Integración de base de datos de percentiles OMS para rango de 5 a 10 años.
- Función de clasificación pediátrica con lógica basada en datos reales.

### Mejorado
- UX: Mejora en la redacción de resultados pediátricos para evitar tecnicismos confusos y mejorar la empatía con el usuario.

## [1.0.1] - 2026-07-16
### Corregido
- Ajuste en validación de rangos de peso y altura para prevenir datos ilógicos en menores de edad.

## [1.0.0] - 2026-06-01
### Lanzamiento Inicial
- Estructura base de la calculadora y conexión con API para persistencia de historial.
